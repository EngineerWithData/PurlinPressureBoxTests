MBMA Cold-Formed C- and Z-Purlin Roof System Test Programs (1975-2000): Pooled Full-Scale, Component and Material Data

Eleven MBMA cold-formed purlin test reports (1975-2000) were pooled into nine populations: full-scale roof assembly tests split by load direction, span continuity and panel restraint, plus the supporting component populations (tensile coupons, cantilever diaphragms, measured cross-sections, computed AISI section properties and service-level response at a common 165 plf load). Pooling is based on each report's own standardized strength-summary table (Table S1) and on the physical test type, so that, for example, single-span standing seam base tests are never mixed with multi-span lapped continuous systems or with uplift tests.

How a row was built

Each paper's tables are joined into specimen rows on the specimen label, values stated once in a table note are filled in for every row of that table, and values absent as columns are reconstructed from the nondimensional ratios the papers tabulate. A reported value is never overwritten by a derived one.

This run derived 189 values and cross-checked 243 that were both reported and derivable.

Aggregation, not matching

Specimens are pooled as independent samples. One paper's specimen Z1 has nothing to do with another's Z1, so nothing is joined across papers. What is compared across papers is the distribution of each variable, not any individual test.

Read the overlap before the mean

A pooled mean over papers that explored different parameter ranges describes the mixture, not the physics. The overlap column says how much of each variable's range all the papers share: where it is low, the pooled statistics are dominated by whichever paper reached that far.

Judgement calls to review

  • The nine groups split the corpus first by test type (full-scale assembly, diaphragm component, coupon, computed section property) and, within full-scale tests, by load direction (gravity vs uplift), continuity (single span vs multi span) and panel restraint (through-fastened vs standing seam). These are the variables the reports themselves treat as defining distinct populations, so rows from different groups should never be averaged together.
  • UNIT TRAP: failure loads are plf per purlin line in every paper except MBMA_7501 and MBMA_7506 (psf of roof area) and the 7501 values are approximate text ('about 40'). The failure_load_unit column is carried in every group so the program can refuse to mix them. Failure moments are kip-in in 8903/9002/9804/9906 but ft-lb in 8802; failure_moment_unit is likewise carried.
  • DEAD LOAD TRAP: what the 'failure load' includes differs by report. MBMA_9906 and MBMA_8404 explicitly include deck and purlin self weight; MBMA_9804 reports applied load only (total carried separately); MBMA_8201, MBMA_8302 and MBMA_8002 state that dead load is excluded or do not say. Any cross-paper strength comparison should flag this.
  • The base-test reduction factor is reported as a fraction in MBMA_9906 and MBMA_9804 (r_value, r) but as a percentage in MBMA_9002 (r_percent); two separate canonical variables are used and a divide-by-100 derivation links them.
  • Radius numbering is inconsistent between reports: MBMA_8201 uses r3 = bottom lip-to-flange and r4 = bottom flange-to-web, while MBMA_8302 and MBMA_8404 use the reverse. The cross-section group maps by physical meaning, following the harmonized definitions, not by symbol number.
  • MBMA_8404 reports yield stress separately for the east and west test purlins; the strength groups carry the east value as yield_stress_ksi. The west value remains available in the coupon group, which keeps one row per coupon.
  • Several papers print ratios in parentheses ('(0.96)') or with stray characters, and the 1975 appendices contain unreadable-character markers '[?]'. The program must treat any cell containing '[?]', 'NA' or a dash as missing rather than coercing it to a number.
  • The MBMA_8302 rotational restraint F-test (one digitized curve) and the MBMA_8201/MBMA_7501 fastener shear and screw pull-over component tests are single-source data with no second contributor, so no group is defined for them; they are retained only as companion information in the source tables.
  • The 1975 instrumentation appendices (MBMA_7501 strain/rotation tables, MBMA_7506 sensor tables) are load-increment time histories, not specimen-level results, and are deliberately excluded from all groups; only their Table S1 strength rows are pooled.
  • failure_load_psf: MBMA_7501 and MBMA_7506 print failure loads in psf of roof area, with no tributary width to convert to plf; they are carried in their own column, not in failure_load_plf (edited by hand 2026-11-04). MBMA_7501 dead load is in psf and is carried as deck_dead_load_psf (the canonical dead-load variable is plf).
  • Hand edit 2026-11-05 (Cris Moen): the database is limited to pressure (vacuum) box tests. MBMA_8002, MBMA_8201, MBMA_8302 and MBMA_8802 (concrete-block loading) are excluded in selection.csv; their members were removed from this plan, and the cantilever_diaphragm_tests and service_response_at_165plf groups, which came only from MBMA_8201/8302, were removed. Notes that still name these papers describe the reports for context only. Unit-label columns renamed load_unit_as_printed / moment_unit_as_printed so their headers carry no unit suffix.
  • Load-direction filter (hand edit 2026-11-10, Cris Moen review): the 'uplift_purlin_assemblies' group (MBMA_8404 Tests 7-15, MBMA_7501) was removed from the gravity set. Those uplift tests are pooled once, in the uplift set; MBMA_7501 moved to the uplift selection.
  • MBMA_8404 Test 13 is dropped before harmonizing (authors call it invalid, p.34) (hand edit 2026-11-10, Cris Moen review).
  • Variable 'failure_pressure_in_h2o' renamed 'manometer_reading_at_failure_in_of_water' (hand edit 2026-11-10): the new concordance appended a wrong unit suffix to it ('failure_pressure_in_h2o_psf'); the values are inches of water.

Note MBMA_8404 'Facing' is opposed (flanges in) while MBMA_9001 'Facing' is same direction.
